# Servo-Arm
A small robotic arm I'm building for fun as a personal project.

**Using**

Design: Fusion 360 + Tinkercad

3D Printing: Bamabu Lab A1 + Bambu Studio

Electronics: Arduino R4 + MB102 + SG90 Servos

Software: C++ (Arduino) + Python
